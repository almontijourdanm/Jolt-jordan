# Jolt Jordan 🧠💼

A fullstack web and mobile job portal platform that helps job seekers enhance their career journey. Features AI-powered resume feedback, resume generator, and a Telegram chatbot for personalized job alerts.

## 🚀 Tech Stack

- **Frontend:** Next.js, Tailwind CSS, TypeScript
- **Backend:** GraphQL, Apollo Server, MongoDB
- **Other Tools:** Vercel, Telegram Bot API, AI Prompt Engineering (Gemini/GPT)
